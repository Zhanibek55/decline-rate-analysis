# Анализ темпа падения переходящего фонда скважин

Интерактивное веб-приложение для расчета и анализа темпа падения переходящего фонда добывающих скважин с возможностью изменения параметров фильтрации и методов расчета.

## Возможности приложения

- Расчет темпа падения переходящего фонда скважин
- Анализ динамики темпа падения в скользящем окне
- Аппроксимация кривых падения добычи по отдельным скважинам (модели Арпса)
- Визуализация результатов анализа
- Загрузка пользовательских данных или использование тестовых данных
- Настройка параметров фильтрации и методов расчета

## Описание проекта
Приложение для анализа темпа падения добычи нефти и газа на скважинах. Позволяет рассчитывать темп падения по различным параметрам, строить графики динамики падения и аппроксимировать кривые падения с использованием моделей Арпса.

## Основные функции
- Расчет темпа падения добычи по горизонтам, месторождениям и скважинам
- Анализ динамики темпа падения во времени
- Аппроксимация кривых падения с использованием моделей Арпса (экспоненциальная, гармоническая, гиперболическая)
- Визуализация результатов с помощью интерактивных графиков
- Учет событий на скважинах при расчете темпа падения

## Технологии
- Python 3.11+
- Streamlit для веб-интерфейса
- Polars для быстрой обработки данных
- Plotly для интерактивных визуализаций
- NumPy для математических вычислений

## Установка и запуск

1. Установите необходимые зависимости:

```bash
pip install -r requirements.txt
```

2. Запустите приложение:

```bash
streamlit run app.py
```

3. Откройте браузер по адресу: http://localhost:8501

## Структура проекта

- `app.py` - основной файл приложения Streamlit
- `utils.py` - вспомогательные функции для расчетов и визуализации
- `sample_data.py` - генерация тестовых данных
- `requirements.txt` - зависимости проекта

## Формат данных

Приложение работает с двумя основными наборами данных:

1. **Данные добычи** - содержат информацию о добыче скважин по дням:
   - `date` - дата
   - `uwi` - идентификатор скважины
   - `horizon` - горизонт/пласт
   - `oil_rate` - дебит нефти
   - `liquid_rate` - дебит жидкости
   - `water_cut` - обводненность
   - `gas_rate` - дебит газа

2. **Данные событий** - содержат информацию о событиях на скважинах:
   - `uwi` - идентификатор скважины
   - `event_date` - дата события
   - `event_type` - тип события (ГТМ, КРС и т.д.)
   - `description` - описание события

Приложение поддерживает загрузку данных в форматах Parquet, CSV и Excel.

## Методика расчета

Темп падения переходящего фонда скважин рассчитывается по формуле:

```
D = 1 - (Σ Q₁ / Σ Q₀)
D% = D × 100%
```

где:
- D - темп падения (доли единицы)
- D% - темп падения (проценты)
- Σ Q₀ - суммарная добыча переходящего фонда в базовом периоде
- Σ Q₁ - суммарная добыча переходящего фонда в текущем периоде

Переходящий фонд формируется из скважин, которые добывали как в базовом периоде t₀, так и в текущем периоде t₁, с возможностью исключения скважин, на которых проводились мероприятия (ГТМ, КРС и т.д.).

## Модели кривых падения (Арпса)

Для аппроксимации кривых падения добычи используются следующие модели:

1. **Экспоненциальная**: q(t) = q₀ × e^(-D×t)
2. **Гармоническая**: q(t) = q₀ / (1 + D×t)
3. **Гиперболическая**: q(t) = q₀ / (1 + b×D×t)^(1/b)

где:
- q₀ - начальный дебит
- D - коэффициент падения
- b - показатель кривизны (0 ≤ b ≤ 1)
- t - время
